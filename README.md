# 👋 Hi, I'm Utsav

**Software Engineer · Backend Systems · SaaS Infrastructure — India**

I build scalable backend systems, APIs, and full-stack SaaS products — especially the parts users usually don't see.

I like building software from the ground up with clean boundaries: authentication, data models, background jobs, observability, integrations, and reliable deployment paths. Currently building fintech software at **Nextbill**, and working on multi-tenant SaaS platforms on the side.

Working mostly with **Go, TypeScript, Bun / Node.js, React / Next.js, PostgreSQL, Redis, Cloudflare Workers, AWS, and Docker**.

### What I'm building now

* **[takenotes](https://github.com/utsavjosh1/takenotes)** — filesystem-first, local-first Markdown notebook for Windows with WSL awareness. Markdown files stay ordinary files, Electron + host runtime server, no lock-in. My most active project.
* **LiveCall Translate** — real-time speech-to-speech translation backend on **Cloudflare Workers** (Hono + Durable Objects + D1 + Queues). Provider-agnostic STT → translate → TTS pipeline over WebSockets, with auth, orgs, uploads, and meeting transcripts/summaries.
* **Learnest** (private) — multi-tenant e-learning SaaS platform with Go microservices backend, React frontends, distributed queues, caching, and object storage.
* **[BackendTemplate](https://github.com/utsavjosh1/BackendTemplate)** — production-grade SaaS starter API: Bun + TypeScript + Hono on Cloudflare (D1, KV, R2, Queues). JWT + rotating refresh + API keys, orgs/roles, R2 uploads, verified webhooks, OpenAPI.
* **[ludoria](https://github.com/utsavjosh1/ludoria)** — *Dead Letter Run*, a small 3D game prototype with React, Three.js, and Rapier. Explore the relay field, activate the pylon, reach the exit. No backend, saves in browser.
* **[GamingMaina](https://github.com/utsavjosh1/GamingMaina)** — Gaming Mania Delhi: Next.js App Router booking + staff ops portal for a gaming lounge (Supabase Postgres + Storage, Better Auth + Google OAuth).
* **[Postly](https://github.com/utsavjosh1/Postly)** — AI job matchmaker built around you: scraping, agents, and recommendations for job discovery.
* **[monitoring](https://github.com/utsavjosh1/monitoring)** — one-click monitoring & DB stack: VictoriaMetrics, PostgreSQL, Redis, and Grafana for small VPS nodes.
